# План отчётов для ИП

**Профиль ИП:** услуги по оформлению разрешительной документации (лицензии, разрешения,
сертификаты, согласования, декларации). ИП — консультант/посредник, не госорган.
**Налогообложение:** УСН «Доходы» (6%).
**Аудитория отчётов:** сам ИП (управление), бухгалтер, ФНС, клиенты.
**Формат:** экран в приложении + экспорт в Excel.

---

## 0. Ключевое допущение — сущность «Работа» (сделка)

Большинство отчётов опираются на одну новую сущность, которой сейчас нет в БД — **«Работа»**:
одна услуга, оказанная конкретному клиенту по конкретному договору.

Минимальный набор полей «Работы»:

| Поле | Назначение |
|---|---|
| Клиент, Договор | связь с существующими таблицами `clients`, `contracts` |
| Тип услуги | разрешение / лицензия / сертификат / согласование / декларация / др. |
| Статус | заявка → в работе → на согласовании → выполнено → оплачено → закрыто |
| Сумма по договору | плановая стоимость |
| Оплата (доход) | вводится **вручную** при поступлении денег |
| Расходы (список) | несколько записей: категория, сумма, контрагент, комментарий — **вручную** |
| Даты | начало, выполнение, оплата |

Это единый источник данных для финансовых и клиентских отчётов.

## Блок 1. Финансы — приоритет №1

### 1.1 Доходы за период
- **Назначение:** ИП, бухгалтер; основа для КУДиР и декларации УСН.
- **Источник:** «Работы» — поле «оплата» + дата поступления.
- **Период:** день / неделя / месяц / квартал / год (выбор).
- **Состав:** дата, клиент, договор/работа, тип услуги, способ оплаты, сумма.
- **Итог:** всего доходов за период.
- **Формат:** экран + Excel.

### 1.2 Расходы за период
- **Назначение:** ИП (прибыль, контроль затрат). Для налога на УСН-6% не обязательны.
- **Источник:** «Работы» — записи расходов + категория.
- **Состав:** дата, категория расхода, контрагент, работа/клиент, сумма, комментарий.
- **Итог:** всего расходов, по категориям.
- **Формат:** экран + Excel.

### 1.3 Прибыль / убыток (доходы − расходы)
- **Назначение:** ИП — главный управленческий отчёт.
- **Источник:** доходы (1.1) и расходы (1.2) за период.
- **Состав:** период (месяц/квартал/год), доходы, расходы, прибыль, маржа %.
- **Итог:** динамика по месяцам (таблица + простой график).
- **Формат:** экран + Excel.

### 1.4 Денежный поток (касса)
- **Назначение:** ИП — когда приходят и уходят деньги, кассовые разрывы.
- **Источник:** оплаты и расходы по датам.
- **Состав:** неделя/месяц, поступления, выплаты, сальдо, остаток нарастающим итогом.
- **Формат:** экран + Excel.

### 1.5 Дебиторская задолженность
- **Назначение:** ИП — кто не оплатил, что просрочено.
- **Источник:** «Работы» со статусом «выполнено», где оплата < суммы договора.
- **Состав:** клиент, работа/договор, сумма договора, оплачено, долг, дней просрочки.
- **Итог:** всего долг, просрочка по срокам (0–30, 31–60, 60+ дней).
- **Формат:** экран + Excel.

### 1.6 Баланс / текущий остаток средств
- **Назначение:** ИП — быстрый срез «сколько денег сейчас».
- **Источник:** доходы − расходы на текущий момент.
- **Состав:** всего поступило, всего потрачено, остаток.
- **Формат:** экран (виджет на главной).

## Блок 2. Продажи и клиенты

### 2.1 Воронка работ
- **Назначение:** ИП — на каком этапе зависают заказы.
- **Источник:** «Работы» — поле «статус».
- **Состав:** статусы (заявка → в работе → на согласовании → выполнено → оплачено),
  количество работ и сумма по каждому статусу.
- **Формат:** экран + Excel.

### 2.2 Активность клиентов
- **Назначение:** ИП — кто активен, кто «уснул».
- **Источник:** `interaction_history` + «Работы».
- **Состав:** клиент, последнее взаимодействие (дата/тип), дней без контакта,
  число работ, статус последней работы.
- **Фильтр:** активные / без контакта N дней.
- **Формат:** экран + Excel.

### 2.3 Выручка по типам услуг
- **Назначение:** ИП — какие услуги самые прибыльные.
- **Источник:** «Работы» — тип услуги + оплата.
- **Состав:** тип услуги, количество работ, сумма доходов, % от общей выручки.
- **Формат:** экран + Excel.

### 2.4 Новые и повторные клиенты
- **Назначение:** ИП — рост базы и удержание.
- **Источник:** `clients.created_at` + «Работы».
- **Состав:** период, новых клиентов, повторных (с ≥2 работами), всего.
- **Формат:** экран + Excel.

---

## Блок 3. Задачи и загрузка

### 3.1 Выполнение задач
- **Назначение:** ИП — дисциплина и сроки.
- **Источник:** `tasks`.
- **Состав:** просроченные / в работе / выполненные; по приоритетам; по клиентам.
- **Формат:** экран + Excel.

### 3.2 Загрузка исполнителей (экспертов)
- **Назначение:** ИП — кто чем занят.
- **Источник:** `experts`, `expert_specializations`, «Работы»/`tasks`.
- **Состав:** исполнитель, работ в работе, выполнено за период, просрочено задач.
- **Формат:** экран + Excel.

---

## Блок 4. Взаимодействия

### 4.1 Статистика взаимодействий
- **Назначение:** ИП — объём коммуникаций и воронка контактов.
- **Источник:** `interaction_history` — поле `type` (звонок, КП, встреча, письмо…).
- **Состав:** тип взаимодействия, количество, динамика по неделям/месяцам.
- **Формат:** экран + Excel.

---

## Блок 5. Документооборот (для клиентов и бухгалтера)

### 5.1 Реестр договоров
- **Источник:** `contracts` (+ `clients`).
- **Состав:** номер, дата, клиент, сумма, статус (active/закрыт).
- **Формат:** экран + Excel.

### 5.2 Реестр актов выполненных работ
- **Источник:** документы в `clients_files` + «Работы» со статусом «выполнено».
- **Состав:** номер акта, дата, клиент, договор, сумма, статус оплаты.
- **Формат:** экран + Excel.

### 5.3 Реестр спецификаций
- **Источник:** спецификации в `clients_files`.
- **Состав:** клиент, договор, номер спецификации, дата, сумма.
- **Формат:** экран + Excel.

### 5.4 Сверка по клиенту
- **Назначение:** клиенту и бухгалтеру — закрывающие документы.
- **Источник:** договоры, акты, оплаты по одному клиенту.
- **Состав:** документ, дата, сумма, оплачено, сальдо.
- **Формат:** экран + Excel (печатная форма).

---

## Блок 6. Для ФНС (УСН «Доходы»)

### 6.1 Книга учёта доходов (КУДиР, раздел доходов)
- **Назначение:** ФНС, бухгалтер.
- **Источник:** оплаты «Работ» по датам.
- **Состав:** дата, основание (договор/акт), клиент, сумма дохода — в порядке поступления.
- **Итог:** нарастающий итог за квартал/год.
- **Формат:** экран + Excel.

### 6.2 Итоги для декларации УСН
- **Назначение:** бухгалтер, ФНС.
- **Состав:** доходы за квартал, нарастающим итогом за год, авансовые платежи.
- **Формат:** Excel.

---

## Порядок реализации (по приоритету)

1. **Блок 1 (Финансы)** — сущность «Работа» + ручной ввод доходов/расходов,
   затем отчёты 1.1–1.3 и 1.5.
2. **Блок 6** — КУДиР и итоги УСН (строятся на тех же данных доходов).
3. **Блок 2** — воронка, активность, выручка по услугам.
4. **Блок 5** — реестры документов и сверка по клиенту.
5. **Блок 3 и 4** — задачи, загрузка, взаимодействия.

## Общий принцип
Все отчёты формируются из одних и тех же таблиц БД + ручного ввода по «Работам».
Экран в приложении — таблица с фильтрами (период, клиент, статус, тип услуги);
кнопка **«Экспорт в Excel»** выгружает ту же выборку в `.xlsx`.
